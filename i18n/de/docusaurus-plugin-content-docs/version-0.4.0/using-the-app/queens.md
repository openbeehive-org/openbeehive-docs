# Königinnen

Openbeehive erfasst, wer die Königin ist, woher sie stammt, wie sie markiert ist und wann ihre Regentschaft begann und endete. Jede Königin bleibt in der Aufzeichnung, sodass jede Beute über die Saisons eine Historie ihrer Zucht aufbaut.

## Was eine Königinnen-Aufzeichnung enthält

Setze oder ersetze die Königin von der Beutenseite aus. Das Formular hat:

| Feld | Was es bedeutet |
| --- | --- |
| Jahr | Das Jahr, in dem die Königin gezüchtet wurde. Bestimmt ihre Markierungsfarbe. |
| Nummer | Eine optionale Züchter- oder laufende Nummer, z. B. „12". |
| Herkunft | Woher sie stammt: Eigenzucht, Buckfast, ein Schwarm, eine Nachschaffung und so weiter. |
| Markierung | Der Farbpunkt auf ihrem Thorax. Folgt automatisch dem Jahr; hake **auto** ab, um eine Farbe von Hand zu wählen. |
| Kommentar | Alles andere: Zuchtlinie, Verhalten, Legemuster, Quellzüchter. |

:::tip Herkunft ehrlich erfassen
„Eigenzucht, Tochter von #214" oder „Vom örtlichen Verein gekauft, Buckfast" sagt dir in zwei Jahren weit mehr als „Königin" je könnte.
:::

## Markierungsfarbe nach Jahr

Openbeehive folgt dem internationalen Königinnen-Farbschema, das alle fünf Jahre entsprechend der letzten Ziffer des Jahres wechselt:

| Jahr endet auf | Farbe |
| --- | --- |
| 1 oder 6 | Weiß |
| 2 oder 7 | Gelb |
| 3 oder 8 | Rot |
| 4 oder 9 | Grün |
| 5 oder 0 | Blau |

Wenn du das Jahr festlegst, wird die passende Farbe ausgewählt. Hake **auto** ab, um eine andere Farbe zu erfassen, falls die gekaufte Königin eine trägt, damit der Punkt in deinen Aufzeichnungen mit dem Punkt auf der Biene übereinstimmt. Für das vollständige Schema und die Merkregel siehe [Königinnen-Markierungsfarben](/knowledge-base/queen-marking-colours).

## Eine Königin ersetzen

Ein Volk hat immer nur eine regierende Königin zur selben Zeit, aber über sein Leben wird es viele haben. Wenn eine Königin nachgeschafft wird, abschwärmt, stirbt oder du bewusst umweiselst, lösche ihre Aufzeichnung nicht. Tippe auf der Beutenseite auf **Königin ersetzen** und gib die neue ein. Openbeehive:

1. Beendet die Regentschaft der vorherigen Königin und erfasst ihr Ersetzungsdatum.
2. Erfasst die neue Königin mit ihrem Einsetzdatum.
3. Behält die alte Königin unter **Königinnen-Historie** auf der Beutenseite, mit Einsetz- und Ersetzungsdatum.

:::tip Umweiseln
Notiere im Kommentar der neuen Königin, *warum* du umgeweiselt hast: schlechtes Legen, stechlustige Bienen, Alter, geplante Linienverbesserung. Muster über mehrere Beuten hinweg verraten oft mehr als jedes einzelne Volk.
:::

## Rückdatierte Einträge

Durchsichten, Ernten und Behandlungen tragen ihr eigenes Datum und werden der Königin zugeordnet, deren Regentschaft dieses Datum abdeckt, nicht unbedingt der Königin, die die Beute heute führt. Liegen eine Umweiselung und eine rückdatierte Durchsicht zeitlich nah beieinander, prüfe die Daten, damit jede Aufzeichnung unter der richtigen Regentschaft landet.

Königinnen-Aufzeichnungen synchronisieren wie alles andere; siehe [Offline und Synchronisation](/using-the-app/offline-and-sync).
