# Beuten

Eine Beute in Openbeehive ist ein einzelnes Volk in einer physischen Zarge. Fast alles, was du Tag für Tag erfasst (Durchsichten, Ernten, Behandlungen), hängt an einer Beute. Jede Beute gehört zu jeweils einem Bienenstand und kann eine Königin haben. Funktioniert offline; siehe [Offline und Synchronisation](/using-the-app/offline-and-sync).

## Eine Beute anlegen

Öffne einen Bienenstand, gib unter **Beute hinzufügen** einen Namen ein und füge sie hinzu (die Liste **Beuten** hat dasselbe Formular mit einer Standortauswahl). Eine neue Beute startet mit dem Status **Aktiv** und ohne Typ. Öffne die Beute und tippe auf die Aktion **Bearbeiten** (Stift), um Folgendes festzulegen:

| Feld | Was es ist |
| --- | --- |
| **Name** | Eine Nummer, eine Farbe, ein Spitzname. |
| **Typ** | Der Rähmchen- und Zargenstandard; siehe unten. |
| **Status** | Der Zustand des Volkes; siehe unten. |

Ein **Foto** fügst du auf der Beutenseite hinzu, indem du auf den Bildplatzhalter neben dem Namen tippst (**Foto entfernen** nimmt es wieder weg).

:::tip
Halte Namen innerhalb eines Bienenstands kurz und einheitlich, zum Beispiel „1", „2", „3". Kurze Namen drucken sich sauber auf QR-Etiketten und sind im Feld schnell zu lesen.
:::

### Beutentypen

| Typ | Typische Verwendung |
| --- | --- |
| Zander | Weit verbreitet in Teilen Deutschlands und Mitteleuropas. |
| Dadant | Beliebt für die Honigproduktion, großer Brutraum. |
| Deutsch Normal | Ein traditioneller deutscher Standard. |
| Langstroth | Der weltweit häufigste Standard. |
| Warré | Ein vertikales Design mit geringem Eingriff. |
| Top-Bar | Horizontale, rähmchenlose Oberträger. |
| Sonstige | Alles, was oben nicht aufgeführt ist. |

Für eine ausführlichere Beschreibung jedes Standards siehe [Beutentypen](/knowledge-base/hive-types).

### Status

| Status | Bedeutung |
| --- | --- |
| **Aktiv** | Ein weiselrichtiges Volk im normalen Gebrauch. |
| **Ableger** | Ein kleines Startvolk, oft ein Ableger oder eine Begattungseinheit. |
| **Weisellos** | Das Volk hat seine Königin verloren und braucht Aufmerksamkeit. |
| **Verloren** | Das Volk ist eingegangen oder abgewandert. |
| **Aufgelöst** | Du hast das Volk vereinigt oder aufgelöst. |

Der Status ist eine Markierung, die du durch Bearbeiten der Beute setzt; nichts ändert ihn automatisch. Eine Beute auf **Verloren** oder **Aufgelöst** zu setzen bewahrt ihre gesamte Aufzeichnung.

## Eine Beute zwischen Bienenständen verschieben

Um eine Beute umzusiedeln, öffne sie, tippe auf die Aktion **Wandern** und wähle den Ziel-Bienenstand. Die Beute behält ihren Namen, ihre Königin, ihr Foto und ihre vollständige Aufzeichnung; nur ihr Bienenstand ändert sich.

### Standort-Historie

Jeder Umzug wird als datierter Eintrag unter **Standort-Historie** am Ende der Beutenseite festgehalten, sodass du weißt, wo ein Volk zu welchem Zeitpunkt war. Nützlich für die Rückverfolgung von Krankheitsexposition und für Wanderimker-Aufzeichnungen.

:::caution
In vielen Regionen unterliegt das Verbringen von Beuten zwischen Standorten Bienengesundheits- und Verbringungsvorschriften, besonders innerhalb von Seuchenbekämpfungszonen. Prüfe deine nationalen oder lokalen Vorgaben, bevor du Völker umsiedelst. Siehe [Krankheiten und Schädlinge](/knowledge-base/diseases-and-pests).
:::

## Die Beutenseite

Eine Beute zu öffnen gibt dir einen Bildschirm mit allem über dieses Volk.

### Kopfbereich und Aktionen

Der Kopfbereich zeigt das Foto, den Namen sowie Status und Typ. Die Aktionssymbole daneben:

- **Stockkarte**: eine druckbare Tabelle aller Durchsichten (mit einem Button **Drucken**).
- **Entwicklung**: Diagramme der bei Durchsichten erfassten Werte (besetzte Waben, Brutwaben, Futtervorrat, Schwarmzellen, Sanftmut, Wabensitz, Varroa, Stockgewicht, Fütterung, jüngste Larve, Temperatur und Luftfeuchte) plus Honigernten im Zeitverlauf.
- **Beute bearbeiten**, **Wandern**, **QR** (zeigt das Etikett der Beute mit den Buttons **Drucken** und **SVG**; siehe [QR-Etiketten](/using-the-app/qr-labels)) und **Löschen**.

### Letzte Werte

Unter dem Kopfbereich zeigen Pills die Werte ungleich null aus der jüngsten Durchsicht: besetzte Waben, Brutwaben, Schwarmzellen, Stockgewicht und Varroa. Ein Tipp auf eine Pill öffnet das passende Diagramm unter **Entwicklung**.

### Königin

Die Karte **Königin** zeigt Jahr, Nummer, Markierungsfarbe, Herkunft und Kommentar, mit **Königin ersetzen** (oder **Königin einsetzen**, wenn keine erfasst ist). **Königinnen-Historie** listet frühere Königinnen mit Einsetz- und Ersetzungsdatum. Siehe [Königinnen](/using-the-app/queens).

### Durchsichten

**Durchsicht erfassen** öffnet das Durchsichtsformular. Darunter sind die fünf jüngsten Durchsichten aufgeführt, die neueste zuerst, jeweils mit Datum, Wetter, Chips, die das Erfasste zusammenfassen (Königin gesehen, Waben, Futter, Schwarmzellen, Sanftmut, Fütterung, Gewicht, Honig, Temperatur, Luftfeuchte, Varroa), der Notiz und etwaigen Fotos. **Alle N Durchsichten ansehen** öffnet das vollständige Protokoll. Siehe [Durchsichten](/using-the-app/inspections).

### Honig und Behandlungen

**Honig** zeigt die Erntesumme der Beute in seiner Überschrift und listet jede Ernte (**Ernte erfassen**). **Behandlungen** listet jede Behandlung (**Behandlung erfassen**). Siehe [Ernten](/using-the-app/harvests) und [Behandlungen](/using-the-app/treatments).

## Löschen gegenüber Stilllegen einer Beute

Ändere den **Status** einer Beute, statt sie zu löschen. Ein Volk auf **Verloren** oder **Aufgelöst** zu setzen bewahrt seine Historie für Jahresvergleiche und Rückverfolgbarkeit. Lösche eine Beute nur, wenn sie versehentlich angelegt wurde; die App fragt nach einer Bestätigung.
